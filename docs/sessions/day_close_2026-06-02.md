## 1. Session Summary

Today opened the **Intelligence Layer** with **Iteration A — Behaviour Intelligence**
(`src/intelligence/behaviour/`), the first stage past preprocessing. It characterises
*normal* machine behaviour descriptively (operational regimes + per-regime statistical
baselines) — the descriptive foundation that the planned `src/models/` predictive
estimators will score deviation against. The day also carried a large package restructure
(`src/data/` → `src/preprocessing/`, `data_generation.py` → `data_generation/`) and a
mypy tooling upgrade.

Shipped:

- **New package** `src/intelligence/behaviour/` (mirrors the established stage convention):
  `io.py`, `policy.py`, `profiles.py`, `baselines.py`, `validation.py`, `reporting.py`,
  `column_groups.py`, `run_behaviour.py`, plus `__init__.py`.
  - `profiles.py` — derives 7 regimes (`stopped`, `startup`, `shutdown`, `alarm`,
    `low/mid/high_production`) from real signals. Non-derivable regimes (`cleaning`,
    `maintenance`, `recipe_change`) are surfaced as `AWARE` findings, **not fabricated**;
    material-change is exposed only as an optional boolean *candidate* column.
  - `baselines.py` — per-`(profile, sensor)` long-form stats (`count`/`mean`/`median`/
    `std`/`min`/`max`/`iqr` always, plus configured `pNN` percentiles). Leakage-safe:
    stats fit on a `train_mask` window only (first 70 %, time-ordered), with a
    `fit_manifest` recording fit window + edges + timestamp for reproducible scoring.
  - `validation.py` — distribution / durations / transitions / coverage reports.
- **Layer dispatcher** `src/intelligence/__main__.py` — registry-based `--component`
  entry point (`python -m src.intelligence [--component behaviour]`); new components
  register with one line.
- **Policy** `configs/behaviour_intelligence.yaml` (Pydantic `StrictModel`); the
  intelligence layer re-uses `src/preprocessing/_common` contracts via thin shims.
- **Tests** `tests/unit/intelligence/behaviour/` — 5 test modules + conftest (29 new
  test functions). Full suite **165 passing**.
- **Reference doc** `docs/intelligence/behaviour_intelligence.md`; `docs/README.md`
  carries an `intelligence/` section.
- **End-to-end artefacts** under `data/intelligence/behaviour/` (git-ignored), organised
  into family subfolders mirroring `data/datasets/{master,specialized}/`:
  - `profiles/profile_labels.parquet`
  - `baselines/baselines.parquet`
  - `validation/{distribution,durations,transitions}.parquet`
  - root `behaviour_fit_manifest.json` + `behaviour_intelligence_report.{json,md}`
  - Verified on the real master dataset (167,331 × 566): 7 profiles, 100 % labelled,
    production edges ≈ [34.6, 38.3] kg/min.
- **Architecture restructure:** `src/data/` → `src/preprocessing/` (`_common` kept
  nested), `src/data_generation.py` → `src/data_generation/generate.py`, the
  `src/preprocessing.py` shim → `src/preprocessing/__main__.py`, `tests/unit/data/` →
  `tests/unit/preprocessing/`. `src/config.py` gained `INTELLIGENCE_DIR`. ~183
  import/path references updated across ~70 files.
- **Tooling:** pydantic mypy plugin enabled in `pyproject.toml`
  (`plugins = ["pydantic.mypy"]`) so `Field(...)` constraints + `default_factory=Model`
  type-check; `pydantic` added to the pre-commit mypy hook deps.

Design boundary captured explicitly: the Intelligence Layer produces **descriptive**
artefacts (profiles + baselines). It fits no predictive estimators — Correlation
Intelligence + PCA are deferred to Iteration B; fitted anomaly models (IF/LOF/Mahalanobis)
remain the job of the planned `src/models/`.

  variance + loadings; reconstruction-error / Mahalanobis "strange sample" flags.

   extending `behaviour/`. Recommend separate components, registered in the
   `src/intelligence/__main__.py` registry (one line each).

   `stopped`/`startup`/`high_production`; decide per-regime vs global.

   keep the leakage-safe train-window discipline.
4. **`_common` placement** — if shared correlation/PCA helpers emerge, decide whether a
   `src/intelligence/_common/` is warranted or to keep shimming `src/preprocessing/_common/`.
