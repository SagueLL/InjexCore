  app-shell/sidebar/page-header) and all four charts (operational-timeline, sensor-health,
  incidents-severity, anomaly-evidence).

**Resolved this arc — the Recharts × React 19 blank-chart trap.** Recharts renders *completely
blank* under React 19 when the transitive `react-is` resolves to v16 (it can't detect React 19
element/Fragment symbols) — and this is invisible to `lint` / `tsc` / `next build`. Fixed with a
`"react-is": "^19"` override in `apps/dashboard/package.json` (the shadcn-documented fix). The
standing lesson: **charts must be verified visually**, not via SSR/curl or the automated gates.

Design boundary held: the dashboard stayed **read-only and demo-data-driven** — no backend
wiring, no Parquet reads, no API. Every view runs on static `demo-*.ts`; the planned path
(Python intelligence → dashboard-ready JSON → Next.js) is not built yet. This matches the v0.1
scope in the frontend rules.
