## 5. Next-Session Plan — Intelligence Layer Kick-off

Anchor: today's `data/datasets/specialized/anomaly_detection_dataset.parquet` (167,331 × 239) is the direct input for IF / LOF / Mahalanobis.

**Scaffolding (follow the 9-file convention used by all four preprocessing stages):**

```
src/models/anomaly/
├── __init__.py
├── io.py                  # load specialized dataset, persist fitted artefacts
├── policy.py              # pydantic config for hyperparameters, contamination, seed
├── splits.py              # time-aware train/calib/test split (no random shuffle)
├── isolation_forest.py    # fit/score wrapper
├── lof.py                 # fit/score wrapper (novelty=True for online scoring)
├── mahalanobis.py         # covariance fit + score
├── evaluate.py            # metric computation, calibration report
├── reporting.py           # JSON/MD run report matching existing convention
└── run_anomaly.py         # orchestrator + CLI

configs/anomaly_models.yaml      # model-family hyperparameters + split policy
docs/anomaly_models.md            # boundary + design rationale (mirrors docs/specialized_datasets.md)
tests/unit/models/anomaly/        # mirror tests directory
```

Also extend `src/preprocessing.py`'s sibling — likely a new `src/training.py` shim, or simply `python -m src.models.anomaly.run_anomaly` — and add a corresponding row to the architecture table in `CLAUDE.md`.

**Decisions the user should make before any coding starts:**

1. **Baseline scope** — pick 1 or 2 of {Isolation Forest, LOF, Mahalanobis} for the first cut. IF + Mahalanobis gives a tree-based vs. parametric contrast cheaply; LOF can land in the second iteration.
2. **Evaluation protocol** — without labelled anomalies (synthetic ground truth aside), commit to either (a) score-distribution-based evaluation + manual labelling of top-k flagged windows, or (b) injected-anomaly recall on the synthetic dataset. The choice changes what `evaluate.py` looks like.
3. **Time-aware split** — for 167k rows of contiguous time-series, the only correct split is forward-chaining: e.g. first 70 % fit, next 15 % calibrate contamination threshold, last 15 % held out. Confirm split ratios and whether to add a gap window to avoid leakage from rolling features.
4. **Contamination prior** — IF and LOF both need it; CLAUDE.md mentions historical 3 % anomaly injection on synthetic. Decide whether to reuse 0.03 or to calibrate from quantiles of the score distribution.

**Concrete first task suggestion for the next session:** scaffold `src/models/anomaly/` with empty modules and a draft `configs/anomaly_models.yaml`, then implement `splits.py` + `isolation_forest.py` + `evaluate.py` as the thinnest possible end-to-end path. Defer LOF and Mahalanobis until the IF path is producing artefacts.
